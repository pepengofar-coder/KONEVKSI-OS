# Konveksi OS

Sistem Manajemen Konveksi Modern — simpel, mobile-friendly, offline-first.

## Features

- 📦 **Modul Produksi** — Barang Masuk, On Progress, Kelaran
- 💰 **Modul Keuangan** — Kasbon Taylor, Invoice Auto-Calculate
- 💸 **Modul Kas** — Cost Harian, Dashboard Ringkas

## Tech Stack

- React 19 + Vite 8
- Tailwind CSS v4
- React Router v7
- localStorage (offline-first)

## Getting Started

```bash
npm install
npm run dev
```

## Deploy

Deployed on Vercel.
